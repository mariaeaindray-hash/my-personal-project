 My Nagasaki Journey
#このWebサイトについて

このWebサイトは、長崎で日本語を勉強していた時の
自分の生活や思い出を紹介するために作りました。日本語を勉強した学校、好きな場所、
よく行ったレストランや食べ物について書きました。
HTMLとCSSを使って作りました。

---

## ページ

- `index.html` → Home
- `about_introduction.html` → My Story
- `places.html` → 長崎で好きな5つの場所
- `food.html` → 好きなレストランと食べ物
- `contact.html` → メッセージフォーム
